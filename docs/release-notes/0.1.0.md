# VoxCtrl Keys 0.1.0

The first version: a voice keyboard for Android that dictates through your own
VoxCtrl server.

## What is in it

- A system keyboard that is one short bar: switch keyboard, microphone,
  backspace.
- Dictation through a VoxCtrl server (0.9.0 or newer) over its
  OpenAI-compatible API.
- Live text: words appear underlined in the text field as you speak, and the
  final transcript replaces them.
- Pairing with a `vxpair_` code, including servers with encryption on
  (certificate pinning, no downgrade to plain HTTP).
- Made for Tailscale: a tailnet address you enter is kept when pairing, and
  the settings say whether the connection to the address is encrypted.
- Retry: a recording the server did not answer for is kept in memory and can
  be sent again.
- A layout that adapts to wide screens and foldables, with the bar's rules
  tested for each Galaxy Z Fold 8 screen and posture.
- Settings for live text, language, names and jargon, and the microphone's
  position on wide screens.
- Privacy: one network destination, audio in memory only, no transcript kept,
  the API key encrypted with the Android Keystore, nothing backed up.

## Known limits

- **Not yet run on a phone.** The logic is unit-tested and the app builds in
  CI; behaviour on a device, and on the Fold 8 in particular, is unverified.
  See [what is verified](../development.md#what-is-verified).
- No typing keys, no on-device recognition, no cleanup, AI processing or
  text-to-speech.

## Requirements

- Android 10 or newer.
- VoxCtrl server 0.9.0 or newer. Client contract revision 1.
