# VoxCtrl Keys 0.1.2

For VoxCtrl servers 0.9.19 and 0.9.20.

## Changed

- **Live text no longer holds up dictations on a shared server.** The
  keyboard marks its live-text clips for the server. A VoxCtrl server 0.9.20
  or newer then runs a clip only when it has nothing else to do, and skips it
  otherwise, so your live text can no longer make a dictation from your
  desktop (or your own final upload) wait behind it. Older servers ignore the
  mark and work as before.
- **A busy server says so.** When a server has too many dictations waiting,
  the bar shows **Server busy** with **Retry** and keeps your recording,
  instead of "Check server settings". Nothing is lost.
- **A server that has outgrown the keyboard says so.** If a future server
  changes how it talks to clients, the bar shows **Update VoxCtrl Keys** and
  the settings explain why, rather than dictation failing in some other way.

## Notes

- A new server (0.9.19 or newer, set up from scratch) is encrypted. Connect
  the keyboard by pasting its pairing code. A keyboard set up with a bare
  `http://` address is told to do that by the server itself.
- Installs over 0.1.1 and keeps the pairing.

## Requirements

- Android 10 or newer.
- VoxCtrl server 0.9.0 or newer. Client contract revision 1.
